# Paan Wala — Apple Preview Radio

This version keeps the original automatic Apple Music preview setup. No MP3 files, YouTube player, API key, or music folder are required.

### Playback behavior
- Random shuffle with **no song repeats until the playlist has rotated**.
- Each available Apple Music preview plays for a **random 24–30 seconds**.
- A short **1.25 second crossfade** makes the playlist feel continuous.
- The custom Paan Wala player remains the only visible player.
- Play/pause, previous, next, and the progress bar still work.

### Important
Apple's preview URLs are short previews, not full-song streams. This version does not attempt to bypass that limitation.

Upload the files in this folder to the root of your GitHub Pages repository. You do not need to upload `node_modules` or the old `dist` folder for this plain HTML/CSS/JS version.
